# 图像验证操作：画幅、事实与结果分开记录

本文件是后续实际出图的操作说明，不是历史评测结果，也不授权自动调用模型。创作、版本确认、编译交付和实际生成是不同阶段；未执行时不得写成通过。

## 画幅选择

不存在统一默认3:2。先遵守用户明确比例；否则由总导演与摄影构图结合创作目的及用途、视觉主体与环境主次、景别和人物占比、横纵空间、动作方向、建筑、前景、留白及纵深确定。只有实质性取舍才询问用户，不按人像/风景或模型习惯分配比例。

比例专业知识见[CA-09~18](../knowledge/camera/aspect-ratios.md#ca-09)，取景与距离协作见[CA-19~23](../knowledge/camera/shot-planning.md#ca-19)。基础知识覆盖4:3、3:2、16:9、21:9、4:5、3:4、2:3、9:16、1:1，不是固定题材表或平台支持保证。

参考图比例不是自动硬约束。延续原构图时优先考虑原比例；仅取人物、服装等元素时按新任务判断。未保存的参考图不能假称已归档或可重新读取。

改比例后复核人物尺度位置、景别裁切、前景遮挡、背景信息、横纵关系、主体层级及留白；局部更新、整体复核，形成新母版并再次展示确认，不只修改宽高参数。

## 比例输出位置

唯一配置为[registry.json](../adapters/registry.json)，具体接口区别见[Adapter契约](../references/adapter-contract.md)。本说明不创建或简化路由。

|目标|按现有配置交付|
|---|---|
|GPT网页端|Prompt块内末尾自然语言比例|
|Midjourney|Prompt块内末尾`--ar`参数|
|Grok网页端|外部画幅控件；正文不重复比例|
|Krea2|所用工作流外部画幅设置；正文不重复比例|
|Qwen Image 2.1、Z-Image|本地工作流外部画幅设置；正文不重复比例|
|Gemini／Nano Banana、Seedream|沿用旧版Prompt块内末尾自然语言比例建议；不保证文字改变实际画布|
|MOSS自然语言／Layout|块外画幅；Layout同时给出准确且相符的画布宽高|
|generic|保留既有外部设置格式|

本版不提供API路由或调用，也不纳入SDXL、Pony、Illustrious、Anima、FLUX（含Klein），不猜参数或静默回退冒充支持。平台可选比例以配置及实际界面证据为准；不支持时保留设计并说明限制，不擅改为3:2。

## 开始与对照条件

先确定目标模型、版本、界面／工作流、可控参数和成本边界；用户明确确认具体母版版本后才编译。新知识和探索草案不等于用户批准。不能为了验证自动启动本地服务或修改ComfyUI。

同一对照组尽量保持已选定的画幅及其他需要控制的条件一致；画幅由该组获确认设计决定，并非统一3:2。特定实验若明确选择3:2，可按其原始条件锁定3:2，不追改历史原图、提示词或记录。比较画幅本身时，明确哪些主体尺寸、取景或位置发生联动，不能声称只改变一个变量。

种子、参考身份、采样等能固定则记录；不能固定就说明。不同版本Prompt只作近似对照，编号相同不等于同种子配对。有混合模型或LoRA时记录实际工作流，不把结果直接归为原版底模能力。

## 每张图的记录与反馈

记录母版ID／版本／哈希、必要知识ID及索引哈希、原始Prompt与编译复核、Adapter ID及版本、设计比例、交付比例所在位置、实际外部宽高设置、成图尺寸、模型版本／工作流／参数／种子、原图路径／哈希、用户评价。个人数据和运行记录保存在发行目录之外，原图与历史记录只读。

逐项观察服装与主体、动作接触、裁切、空间、层级、影形落点、材质和技术缺陷，回映母版事实ID。区分实际观察、合理推断、未知；不以漂亮、电影感等抽象词代替执行证据。文字覆盖或程序pass不证明语义或图像通过。

未生成时`execution_status`为pending、`result`为null；实际检查使用pass/fail/uncertain，无法判断保留uncertain。区分设计冲突、Compiler遗漏、Adapter改义、模型未遵循、外参不符、随机差异及观察歧义；缺少链路证据时不猜根因。

## 待用户决定的专项

人物约束可能减弱，需要后续专项对照；目前仅登记，不改规则、不推定根因、不自动出图或重新安排已有独立Agent验证。是否启动及对照范围由用户决定。

小规模试验用于发现问题，不作为最终验收标准；24张也不是固定门槛。V2.0仍须大量真实用户反馈和持续迭代。
