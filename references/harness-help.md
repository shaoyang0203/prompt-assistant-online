# Prompt Assistant Online V1.2 Harness 使用说明

Harness 保留 VIP 的探讨、六步视觉设计、七类知识和模型适配，在独立存储中增加反馈、候选改进、对照实验、日志、回滚与迁移。

每次回复都有真实状态：开表示允许按证据门槛开展优化；关表示不开展新优化，但个人偏好和已验证经验仍可用；不可用表示无法验证可靠持久写入。首次使用会询问是否开启，未回答不会自动改变状态。可说“递归优化 --开”或“递归优化 --关”。自动写入经验还需要你明确授权。

环境检测会真的创建临时文件、写入并同步、重读比较、删除，再验证配置与数据快照保存；只看目录存在不算通过。没有执行工具、无法访问目录、读写或清理失败，会给出实际原因。只读 Skill 配合可写的外部数据目录也能工作；仅有对话或临时附件存储不能宣称永久保存。不可用时仍能正常设计，反馈只能暂存在当前对话。

评价分为“特别喜欢、喜欢、一般、厌恶”。只说特别喜欢不会被解释为喜欢所有细节；指出喜欢什么才形成具体证据。一般不是厌恶；没有原因的厌恶不会自动成为禁令。Agent 推断只记弱证据，并有明确标签。长期、跨模型偏好及永久禁令按你的明确意图记录；模型特定问题只作用于那个模型。

个人偏好回答“你喜欢什么”；设计经验回答“某种方法在什么条件下稳定有效”。单次审美意见不会直接修改全局设计规则。候选通常需三个独立方案、两类场景的明确证据，再做前后对照和其他题材验证。通过且获授权后才应用；失败和回滚同样保留记录。没有实际出图证据，最多说明文本检查通过。

默认数据目录为当前用户主目录的 `.prompt-assistant/harness`，也可明确指定独立目录。运行时会显示实际位置。官方包不写入私人数据。共享电脑不同用户应指定不同目录。数据不会自动上传、自动调用生图或自动执行历史文本。日志包含修改原因、来源、前后差异和测试记录，可能涉及私人创意，请自行保管。

你可以说“查看我的个人偏好”“纠正这条偏好”“忘记这次反馈”“清空个人偏好”“暂停学习”“停用已有偏好”。暂停学习和停止应用是两个设置；与递归优化开关独立。永久禁令的修改会先处理冲突。忘记仅删除当前目标及关联记录；清空移除当前偏好及派生数据。两者均保留历史快照、审计文件和备份，因此不代表历史原文已彻底擦除；历史与外部导出文件需另行明确处理。

可直接说：

- 导出我的个人偏好文件。
- 导出我的 Harness 修改记录和优化经验。
- 导出完整 Harness 迁移包。
- 导入我的 Harness 迁移包。

导入会校验、备份、合并并报告冲突，重复 ID 不重复添加，不覆盖核心设计、不自动开启引擎或晋级候选。仅支持明确兼容的数据版本；旧 VIP Markdown 需要先核对转换。无法创建文件时会明确报告，提供可手工保存的 JSON 文本不等于已经导出成功。

能力限制：这是一套 Agent 协议和本地辅助程序，不是常驻后台学习服务。需要 Python 3.10+ 和宿主允许的持久文件访问。脚本验证结构和门槛，不能凭空判定艺术质量或证据真实性；语义、评分与视觉判断仍由 Agent 和用户负责。当前交付只验证 Windows 本地执行，其他平台、无工具聊天环境和第三方附属存储尚未实测。

技术数据和迁移规则见 [harness/README.md](../harness/README.md)；Agent 操作协议见 [harness-protocol.md](harness-protocol.md)。
