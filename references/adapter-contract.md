# 基础 Model Adapter

自然语言编译继续通用优先；只落实用户已确认的模型与表达规则，不宣称完整模型能力已迁移。路由配置为 [registry.json](../adapters/registry.json)，本地 [adapter.py](../scripts/adapter.py) 从配置读取画幅排版；语言和自然语言组织由宿主LLM执行。MOSS显式Layout另有结构检查；宿主无Python时仍可创作，但不能宣称已经执行程序校验。
允许翻译、语序、分段、等义合并及交付排版；不得改变主体数量、动作、场景、空间、主光、颜色或已确认风格。
用户未指定目标时可以交付通用版，不猜专属参数；默认风格不反复提问。
最终正文以独立代码块交付。确定目标后，按[目标模型加载表](model-routes.md)读取对应专属文件；语言、表达结构、比例位置和特殊格式均执行目标规则，不由模型判断“本次是否需要读”。目标未知时可以明确使用generic，不猜模型。

专属文件与[注册表](../adapters/registry.json)分工：前者给LLM编译依据，后者供程序读取既有交付配置。注册表的compiler_policy.reference只是可核验文件指针，不是自动加载器或阅读证明。Python不翻译、不替代LLM语义复核。

## 语言偏好覆盖（H-01，用户已确认）

用户长期语言偏好（例如“提示词一律中文”）覆盖各路由的 `default_prompt_language`，包括 Qwen Image 2.1 的英文默认。规则只有一条：**语言可换，结构不换。**

- 换的只是正文语言；该路由的表达组织、单段或分段要求、观察式或自然语言风格、画面文字逐字保真、比例位置一律不变。
- Qwen 改中文后仍是单段、第三人称、现在时、陈述口吻的观察式描述，不退回流水句、标签串或Markdown结构。
- 覆盖发生时在交互层提示，例如末尾一行 `[语言：中文（路由默认英文）]`；用户可关闭提醒。
- 这是产品语言约定，不宣称中文在该模型上必然优于英文；实际效果未验证。程序不自动翻译，也不证明宿主已遵守。

## 接口与交付边界

本版不提供API路由或API调用。SDXL、Pony、Illustrious、Anima及FLUX（含Klein）已由用户明确不纳入本版；不得静默回退generic冒充支持，也不从只读旧版自动补回这些路由。该范围决定不修改V1.4.0或删除其能力资料。

来源、设计ID、确认记录、内部说明不进入正文。九区域可读母版中的比例展示用于设计确认，不是最终交付的“块外重复”；工具返回的结构化比例元数据也不要求宿主再次显示。最终交付优先使用`formatted`，不要在它外面再重复比例。

只交付已登记的模型路由；未实现的LoRA/Tags专用能力不能凭名称宣称已支持。
通用 Prompt 优先。在出现大量实际不兼容证据前，不针对每个模型单独改写优化。
母版比例先由设计确定。Adapter只把相同宽高比转换为路由要求的表达，不做视觉重设计、自动裁切或回落3:2。其他路由未登记可选集合不等于无限支持。具体接口支持仍需真实验证。

程序检查版本、比例值、路由及明显的重复比例语法；LLM复核实际路由后正文与外部设置，发现语义化擅改/重复也须fail/uncertain。无法穷举所有自然语言写法。无Python宿主只有指令约束，不能称为程序门禁。
