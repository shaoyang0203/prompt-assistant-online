# 视觉设计系统 · 总纲

只在内部使用。本目录是 V1.2 的视觉设计知识体系，取代旧版中分散的框架代码、视觉语言索引与题材候选池。知识用于设计，不是必须逐条命中的菜单。

## 七类知识

| 模块 | 文件 | 负责 |
|---|---|---|
| 一 | `01-人物身份与情境.md` | 身份、时代、地域、角色、场合，人物与场景服装道具的协调 |
| 二 | `02-主题与画面构思.md` | 从主题或事件中找到画面切入点，确定瞬间、主导类型与第一视觉锚点 |
| 三 | `03-动作与环境互动.md` | 姿态、重心、支撑、手部任务、视线，人物与道具场景环境的关系 |
| 四 | `04-构图与空间.md` | 景别、机位、布局、前后景、留白、遮挡、虚实与纵深 |
| 五 | `05-光线色彩与材质.md` | 主光、明暗分离、配色关系、皮肤服装环境材质 |
| 六 | `06-审美与视觉语言.md` | 抽象审美的多义转化、视觉语言参考、题材候选、风格强度 |
| 七 | `07-约束与质量检查.md` | 第五步的约束判断；第六步的精简、完整性与交付检查 |

## 使用方式

1. 正式设计必须完整读取本目录的 `00-总纲.md` 与 `01—07` 七个模块（共八个文件），按 SKILL.md 的六步流程依次使用：第一步读 01，第二步读 02，第三步读 03，第四步读 04、05、06；第五步读 07，用信息预算判断硬约束、设计决策与可自由发挥的空间；第六步读 07，完成精简、完整性与交付检查。交付前读取《Adapter与交付》；进入 Qwen T2I 路由时另读《Qwen-Image-2.1-T2I》。不得以任务简单或只加载部分模块为由跳过六步中的任何一步。

模块七同时服务第五、六步：第五步只做约束程度判断，不执行精简；第六步执行精简、完整性复查和交付前检查。
2. 模块提供知识、方向与候选，不规定必须使用的元素、姿势、构图或风格。任何具体方法只要服务当前画面目标即可采用；不服务目标的即使出现在参考里也不用。
3. 抽象要求按模块六的多义解读转化，不固定映射为唯一的服装、构图、光线或色彩组合。
4. 用户明确指定的内容优先于本目录的全部知识。
5. 模块内有出处限制的条目按指示使用：导演、摄影师、片名只作内部检索键，不进入母版与成品；语义分析不在回复中展示。

## 基本原则

- 先理解人物与情境，再设计画面；不先套风格模板。
- 每个决定都指向可见结果：位置、动作、光线、颜色、材质、清晰程度。
- 丰富不等于堆砌；简洁不等于空白。细节密度围绕视觉重心组织。
- 不设具体姿势、道具或视觉手法的黑名单；要避免的是缺乏设计意图的机械重复。
- 画面不强制有故事或复杂动作；安静、停顿、日常同样成立。
