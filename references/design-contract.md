# 素材到画面的设计合同

本合同落实 SKILL.md 的六步流程，不增加另一套步骤。目标是让最终提示词承载设计完成的画面，而非用户原文的语言转换。对所有模型、短词与抽卡生效；不依赖 Harness 开关或 Python。

## 1. 输入先作设计理解

先执行 SKILL.md「设计前先确认目标模型」：尚未选择目标模型或通用交付时先询问并等待，再进入本合同的设计流程。按完整对话识别创作意图。普通陈述也可能是明确要求：“红色外套、侧身站在门口”已经锁定相应内容，不需要用户另说“必须”。“比如”“可以试试”和风格比喻按语境识别为建议或审美素材；不可为了增加自由度把明确要求降成建议。用户已选中的方案同样是约束。

- 已定项：要保真的主体、数量、身份、衣着、动作、场景、构图、光色、文字、比例等具体决定。
- 审美与情境素材：要表达的主题、感觉、参考方法、尚未选中的例子；转成当前场景的可见关系，不原样贴成空泛标签。
- 开放项：用户尚未决定、而本幅画面需要的切入点、观看位置、人物与环境关系、主次层级、光色与材质组织。

“直接生成”“不要解释”“短一点”改变交互或表达，不撤销设计工作。只有用户明确要求仅翻译、仅校对或只转换格式时，才按该局部任务保真处理，不借本合同擅自设计。已有完整 Prompt 的纯模型迁移保留画面；用户同时要求重新设计时，才在其授权范围内重构。输入完整时无需为了证明做过设计而新增内容。

## 2. 母版必须是画面结果

按原六步依次形成母版。用简短的设计事实说明：这幅图选了什么瞬间、第一眼看哪里、从哪里观看、人物与场景怎样连接、主光怎样作用、颜色与材质怎样分工。事实直接进入母版相应字段；不用另写过程报告，不记录逐步推理。

用户锁定的关系直接继承；开放的关键关系要作决定；确实不适用于当前景别或媒介的细节可以省略。面部特写不补全身动作，平面剪纸不强制摄影景深，纯净背景不强制塞前景道具。静止、居中、朴素都可以是有效设计。

新增信息的价值来自可见的画面关系，例如人物与背景的尺度、视线和留白的对应、主光如何显出衣料与皮肤的区别，而非新增词语或物体的数量。不要以“至少新增 N 项”、提示词字数或打勾数量验收设计。

## 3. 编译只接收设计结果

Adapter 从已验收母版取材，可以调整语言、语序、长度与平台表达。不可将用户原文直接作为编译输入，也不可先翻译原文后倒填母版。压缩前先判断哪些关系使画面成立；这些关系必须在短词中仍然可恢复。

母版默认不对外展示。用户只要 Prompt 时按现有交付格式出词；内部核对不构成再次询问或额外输出的理由。用户要求查看设计时，提供设计结果和简短的保留/补全摘要，不提供冗长推理。

## 4. 交付前检查实际产物

核对用户材料、母版和最终提示词，检查以下事实，而非填写“六步已完成”：

1. **保真**：用户指定项在母版与成品中均有对应；没有把例子强制照搬或擅自更换主题。
2. **设计完成度**：需要设计的关键关系已有明确结果。若材料未给主光或构图，成品仅写“优美构图、电影光线”，仍未完成。
3. **相互配合**：动作、支撑、空间、光色与材质可以在同一画面成立；多个好看的词不能代替协调关系。
4. **编译保留**：使方案成立的关键决定在最终 Prompt 中可辨认，未被短词、抽卡或 Adapter 丢弃。
5. **反直译检查**：忽略语言变化、同义替换、质量词和无关装饰后，原本开放的画面问题是否仍没有答案？若是，返回对应设计步骤；不要继续在同一翻译稿上堆词。

用户输入已经完整，或明确只做翻译/校对/迁移时，不要求出现新增设计差异。上述检查不能通过关键词搜索证明；本合同也不把填写母版等同于图像质量合格。

## 5. 对照例：缺少关系，不是缺少形容词

素材：“成年女性在旧书店看书，有电影感，直接生成通用英文提示词。”

失败方向：“A beautiful adult woman reading in an old bookstore, cinematic, detailed, beautiful lighting.” 它只把素材换成英文，没有决定观看位置、空间或光线行为。

可行设计之一：视线高度的腰上侧面构图；人物立于靠窗书架旁，书摊开在腰前，目光落在书页；侧窗光照亮脸颊和纸页，身后的深色书架保留可辨认的纵深；哑光书布封面与纸页柔亮受光形成区别。

这里有价值的是人物、书、窗光和书架之间的安排，不是“书店必配窗光”。另一幅可以用桌灯、俯视或深焦，前提是场景与用户要求允许。此例仅解释验收差别，不是待套用的画面模板，也不是一条完整的模型交付样例。

## 6. 宿主与验证边界

宿主可将母版和最终成品作为两个独立产物传递给编译与审核环节；若没有母版，编译环节应返回设计阶段。自然语言 Skill 本身无法拦截宿主绕过流程，不能声称“所有 Agent 已被程序强制执行”。没有文件或执行工具时仍按本合同设计与核对，不假报工具检查通过。

行为回归任务位于 [design-cases.json](../tests/design-cases.json)。评测时先只给原始任务和技能，让被测模型完成；再由评审检查产物，不能把参考答案喂给被测模型。存储测试、设计文本评审、独立模型执行和实际出图分别报告，不互相替代。
