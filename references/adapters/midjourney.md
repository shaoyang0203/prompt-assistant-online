# midjourney 专属编译规则

目标确定为本路由后必须读取本文全文，并同时遵守[公共Adapter契约](../adapter-contract.md)。完整正文仍在本任务上下文且文件未变时可复用；只有名称、摘要或旧记忆不算已读。本文件整理既有规则，未重新核实官网或扩大模型能力。

## Midjourney正文表达（MJ-01，用户已确认）

适用于当前已实现的 `midjourney / mj` 路由，由宿主LLM编译和语义复核：

- 正文直接描述成品画面，避免“请帮我画、请让画面更高级”等对话式指令和审美解释。
- 可以使用紧凑的自然语言短句，不强制改成标签串。精简重复表达，不删已确认设计，不设统一字数上限。
- 不把九区域字段、内部讨论和审核记录抄进正文。既有画幅由Adapter在块内末尾输出 `--ar W:H`，不改动其他参数和语言约定。
- 规则约束表达方式，不证明模型执行效果，也不允许通过删除设计事实取得完整性检查pass。

官方核实：2026-11-01，[Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)。官方建议清楚、简短的画面描述，避免冗长指令，同时说明重要细节需要保留、细节减少会降低控制；未规定本项目通用字数上限。实际图像效果待验证。

## Midjourney加强压缩（MJ-02，用户已确认）

适用于 `midjourney / mj`，在既有编译与语义复核中执行，不增加内部协调或自动重试预算：

- 直接从已确认母版编译紧凑版本，不先生成长篇通用Prompt再做少量删改。通用优先仍指使用自然语言和共同设计事实，不要求先交付一份长稿。
- 同一视觉事实只表达一次；用简明关系合并主体、动作、服装、位置等关联信息，删除铺垫、解释、重复强调和无视觉作用的修饰，不把不同事实误并成一个含混词。
- 不逐项展开九区域，不为覆盖专业领域而补写描述；只表达母版中实际需要成图的信息。已确认可编译事实仍须完整覆盖，不因归入某个区域或被认为次要而自动删除。
- 压缩到继续缩短就会损失关键含义为止，不设统一字数上限。用户明确要求、具体画面文字、数量和设计事实之间的关系保持原义；完整性检查继续适用，fail或uncertain不得放行。
- 若保留全部设计后仍过长，应回到总导演，提出具体的次要设计删减建议和损失，由用户确认修改后的具体母版版本后再编译。Adapter不得自行删减或把遗漏登记为pass；不能直接沿用旧母版确认和旧成品复核。

本条加强表达压缩，不修改人物约束、其他模型的压缩策略或既有 `--ar` 交付位置。是否改善图像效果尚待实际对照验证，不把长度直接判作失败的唯一原因。

依据：2026-11-01已读取的[Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)建议简短直接、保留重要细节；以上压缩步骤及母版确认边界是用户批准的产品实施规则，不冒充官方字数标准。

## Midjourney正文语言（MJ-03，用户已确认）

适用于 `midjourney / mj`：最终提示词正文默认使用简洁中文；用户明确要求英文或其他语言时按其要求输出。继续执行MJ-01直接画面描述和MJ-02加强压缩规则，不因切换语言扩写或改变设计。

画面内文字逐字保留用户指定原文及原始语言，不随正文翻译；知识库现有英文示例保持原样。既有画幅仍在块内末尾使用 `--ar W:H`。

这是用户确定的产品语言约定，不宣称中文已实测优于英文。语言选择和语义复核由宿主LLM执行；Python Adapter不自动翻译，也不能证明宿主已遵守语言要求。正文或路由配置改变后，按Compiler契约重新复核实际最终成品，不沿用旧pass。

## Midjourney Raw与Stylize（MJ-04，用户已确认）

适用于 `midjourney / mj`，由宿主LLM结合已确认设计判断：

- Raw（`--raw`）减少Midjourney自带的风格处理；Stylize（`--s`或`--stylize`）控制模型风格化介入。较低Stylize倾向贴近描述，较高值给予更多艺术发挥，但可能偏离具体细节。
- 需要减少模型自行发挥、加强具体描述遵从时，可以建议Raw或降低Stylize；希望保留更多艺术发挥时谨慎选择，不把某套参数设为固定配方，也不保证开启后一定改善效果。用户明确指定的设置优先，不擅改其选择。
- 默认以官网最新主力模型的能力说明为依据选择具体取值，不以平台默认值代替设计判断；未知时说明未知，不编造推荐数值。参数不改变母版视觉事实，仍需按既有Compiler契约复核。
- 确定采用的参数在同一代码块末尾参数区表达，可放在既有 `--ar W:H` 之前，不在参数后追加普通描述，不在块外重复。使用本地工具时，参数文本置于候选最后一段，Python仍只执行现有排版，不自动选择Raw或Stylize；最终成品须重新复核，不能沿用调整前的pass。

官方核实：2026-11-01，[Raw](https://docs.midjourney.com/hc/en-us/articles/32634113811853-Raw)、[Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize)。本条补充选择知识与交付说明，不宣称已经验证实际图像效果，也不迁移其他专用参数能力。

## Midjourney模型基准（MJ-05，用户已确认）

默认以Midjourney官网最新主力图像模型为编译与参数知识基准，不以旧版兼容为默认路径，也不把版本选择变成常规追问。用户明确指定其他版本时按其要求处理。

2026-11-01官网核实：当前默认主力模型为V8.2，见[官方Version页面](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)。V8.2是本次核实记录，不是永久锁定值；后续正式更新路由知识时以届时官网为准，不能把历史参数记录冒充最新能力。

既有自然语言编译、简洁中文、加强压缩、画幅与Raw/Stylize选择规则继续适用。本条是宿主LLM的编译参考，不表示本地工具已经执行模型切换或调用图像模型。
