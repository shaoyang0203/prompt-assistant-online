# 视觉语言索引（D / P / C / R / S）

只在内部使用。索引条目不得整行照搬进成品；把选中的特征展开为可见事实后再写入母版（判定标准见 SKILL.md「抽象语言转可见事实」「强制正向可见事实」）。索引中的环境、天气和表面状态均须服从当前场景依据；可借鉴用光、构图和材质方法，不因索引提到潮湿、风沙或雾就自动加入这些条件。

## D 类索引（含视觉语言出处）

每条末尾的“内部参考”是该视觉语言的检索键，只在内部使用：用户提到这些人名或片名时，先定位到对应条目，再从该条目提取构图、机位、用光、色彩、空间与材质方法；不得提取角色、心事、演员相貌或剧情事件，也不把某位作者的全部作品视为同一套风格。人名与片名不得出现在视觉母版与任何 Adapter 成品中。

### P09 暖金古风夜宴

- 主题气质：新中式幻想宫廷、贵妃夜宴与奢华古风写真融合，从容、柔媚、精致、华丽。
- 光线：暖色宫灯作为环境光，正面或侧前方使用柔和美妆主光，侧后方形成金色轮廓光；面部明亮柔润，背景保持深暖层次与奶油散景。
- 色彩：琥珀金、蜜糖橙、珊瑚粉、桃肉色和深红木色组成暖色同类色调，黑色发丝或深色背景提供视觉压重。
- 材质：薄纱、丝绸、刺绣、珠宝流苏、光滑金属、黄铜器物、灯笼与深色木作具有细腻反光和层次。
- 人物：精致古风妆面、通透肤质、从容姿态与含蓄眼神；身份、数量、动作和服饰形制以用户需求为准。
- 环境：宫廷室内、宴饮陈设与暖灯纵深作为可选元素，根据主体和叙事选择必要内容。
- 成像：柔焦美妆光、清晰五官与珠宝细节、浅至中等景深、温润高光和精致商业人像完成度。
- 画幅：保持自由，根据用户意图选择横幅、竖幅或方幅。

### P10 克制暖金宫廷

- 主题气质：延续新中式幻想宫廷、贵妃夜宴与奢华古风写真气质，以克制、温润、通透的摄影表达呈现人物关系。
- 曝光与影调：中等偏亮曝光和舒展中间调，人物比背景明亮约一档；深色木作保留暖棕纹理与通透暗部，前景金器亮度低于人物面部。
- 光线：侧前方使用面积宽大、经过双层扩散的偏中性柔暖美妆主光，形成宽缓连续的明暗渐变；柔和反射补光打开眼窝、下颌、服装和桌面暗部；宫灯提供温润环境光与轻柔金色轮廓光。
- 高光：面部、肩颈、胸前、宫灯和金属的高光从中间调平缓过渡至柔亮峰值，边缘柔软，带轻微奶油辉光和胶片式高光肩部。
- 色彩：低饱和暖金体系；以深褐木色、乌木棕、沉稳深绛红和柔和焦糖棕建立色阶；蜂蜜金与淡琥珀色集中于宫灯、金器、刺绣和轮廓高光；女性服装使用低饱和杏桃粉与灰调旧玫瑰色。
- 肤色：女性肤色以柔亮象牙白和低饱和桃粉色为基底，面颊、耳部和关节带淡玫瑰血色，阴影保持柔和中性桃棕；男性肤色采用自然暖米色与轻微桃红血色；人物皮肤与金色环境保持自然色彩分离。
- 材质与成像：保留自然透光感、细微毛孔、柔和油脂反射和真实面部体积；薄纱、丝绸、刺绣、黄铜与珠宝呈现柔润受控的反光；整体微反差适中，局部锐度柔和，背景形成奶油散景。
- 画幅：保持自由；双人场景明确左右位置、视线、动作连接和前中后景层次。

这些条目保留华丽造型、配色、光线和材质的具体设计参考，按当前需求组织；不构成固定成品答案。人物心事、关系与故事仍以用户输入为准。
