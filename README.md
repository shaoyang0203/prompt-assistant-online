# 视觉导演系统 V1.5.2

把素材设计成画面，再把画面编译成提示词。

一个宿主语言模型承担总导演和五个专业领域的工作：先给出完整构思，再建立九区域视觉母版，经你确认具体版本后才编译成通用自然语言提示词，最后按目标模型的路由交付。**不自动出图，不调用任何图像模型。**

## 能做什么

V1.5.2将基础设计检查与按需知识查阅分开：已知ID直接读，同一任务有效正文可复用，只补读受影响部分。没有未决问题不强查，有未决问题不以要求明确或省token跳过。此改进是宿主执行协议，尚未实测跳过率或token收益。

- **三套完整构思**。同一需求给三个真正不同的方案，差异来自瞬间、空间、镜头与光色，不是换形容词；必要时给五套。
- **九区域视觉母版**。意图约束、创意瞬间、主体层级、人物、场景、动作与空间、摄影构图、光影色彩、材质表现，逐条列出实际设计，不用“已完成”概括。
- **具体版本确认**。选方向不等于确认母版；必须看到完整版本并明确确认，才进入编译。
- **100 条专业知识库**。总导演 15、摄影构图 23、人物美术 12、场景美术 10、光影色彩 28、材质表现 12，43 项来源，标注技术依据、实践方法、作者推导与未验证假设四种证据等级，可离线检索。
- **画幅按画面决定**。没有统一默认值；改比例后会复核人物尺度、裁切、前景、背景、空间关系与留白。
- **编译门禁**。结构检查加语义复核，成品与母版哈希互绑；漏项、多项、比例被偷改、画面文字未逐字保留都会被拦下。
- **11 条模型路由**。分别决定比例放在代码块内还是块外、用哪种语法表达。
- **偏好模板**。跨会话记住你的要求：五个维度、三种作用（默认填充／倾向／避开），可绑定场景与模型；默认全部关闭，你说了才生效。
- **只读存档与推断**。整体赞赏只保存母版与成品原文，不偷偷改偏好；只有你明确要求时才读存档、提候选，且一律待你确认。
- **说明书**。12 个功能模块，只在你要看时展示。

## 三分钟开始

1. 让宿主读取本目录的 `SKILL.md`（技能入口）。
2. 直接说需求。想先看用法就说“说明”。
3. 想让偏好跨会话保留，准备一个**源码之外、跨会话不变**的目录：

```powershell
$py = '<你的 Python 解释器绝对路径>'
$skillDir = '<技能目录绝对路径>'
& $py -B -X utf8 "$skillDir\scripts\prefs.py" --data-dir <数据目录> init
& $py -B -X utf8 "$skillDir\scripts\prefs.py" --data-dir <数据目录> status
```

没有 Python 也能正常创作，只是偏好、存档和任务记录不可用——此时系统会明确说明，不会假装保存过。

## 一次创作怎么走

```
三套完整构思 → 你选方向 → 九区域母版 → 你确认这一版 → 编译 → 按路由交付
```

母版是不可变的：任何修改都会生成新版本，重新展示、重新确认。改比例、改设计都要走同样的复核。

## 知识库

`knowledge/` 下是 100 条分级条目，43 项来源。每条标注 `T`（资料支持的技术关系）、`P`（专业实践方法）、`C`（针对当前画面的推导）、`M`（图像模型执行假设，未验证）——四者不能互相冒充。

```powershell
& $py -B -X utf8 "$skillDir\scripts\knowledge.py" search '雨夜 湿地 反射' --limit 3
& $py -B -X utf8 "$skillDir\scripts\knowledge.py" show LC-15 MA-05
& $py -B -X utf8 "$skillDir\scripts\knowledge.py" audit
```

没有 Python 时按 `knowledge/README.md` 的索引直接读文件。

## 偏好模板与存档

模板是偏好的唯一形式，取自**母版的设计方向**，不取自提示词。模板名可以抽象，属性必须是可见事实——写“电影感”会被程序拒绝，写“低对比侧逆光、面部明暗过渡平缓”才行。

| 概念 | 说明 |
| --- | --- |
| 维度 | 主体／光影／配色／镜头／材质；不同维度可叠加，同维度只允许一个默认 |
| 作用 | 默认填充（没说就填）／倾向（同类场景偏向）／避开（设计时排除） |
| 作用域 | 场景 + 模型；模型经验不跨模型传播 |
| 开关 | `record` 记录、`apply` 使用、`remind` 提醒 |

整体赞赏只进存档（母版快照 + 成品原文），不生成模板。系统不会在创作时推断偏好；只有你要求时才推断，结果全部待确认。规则细节见 [偏好协议](references/preferences.md)。

每轮回答末尾会出现一行 `[模板生效：…]`，列出本次实际生效的模板；没有就不显示，也可以关掉。

## 画幅与路由

没有统一默认 3:2。用户比例优先；否则按用途、主体主次、景别、横纵空间、动作方向、建筑、前景、留白整体决定。

| 路由 | 比例位置 | 说明 |
| --- | --- | --- |
| GPT 网页端 | 块内末尾 | 自然语言表达 |
| Midjourney | 块内末尾 | `--ar W:H` |
| Grok 网页端 / Krea 2 | 块外 | 界面或工作流设置 |
| Z-Image | 块外 | 中文自然语言正文 |
| Qwen Image 2.1 | 块外 | 观察式单段描述 |
| Gemini／Nano Banana、Seedream | 块内末尾 | 自然语言表达 |
| MOSS | 块外 | 自然语言或 Layout，Layout 须给准确画布尺寸 |
| generic | 块外 | 外部设置 |

用户长期语言偏好会覆盖路由默认语言（包括 Qwen 的英文默认），但**结构不变**：仍是单段观察式描述，只是换语言。细则见 [Adapter 契约](references/adapter-contract.md)。

平台不支持既定比例时说明限制，不替你改成 3:2。

## 本地工具

全部只用 Python 标准库，需要 3.12 或更高。用绝对路径调用解释器，建议始终加 `-B -X utf8`。

| 工具 | 作用 |
| --- | --- |
| `scripts/pa15.py` | 创作链：任务快照、母版展示、确认、编译、交付 |
| `scripts/prefs.py` | 偏好模板、存档、推断、开关 |
| `scripts/knowledge.py` | 知识检索与索引审计 |

```powershell
$skillProduct = $skillDir # 上文设置的技能目录绝对路径，不依赖当前工作目录
& $py -B -X utf8 "$skillProduct\scripts\pa15.py" --help
& $py -B -X utf8 "$skillProduct\scripts\pa15.py" --data-dir <数据目录> --task t1 new --request '<需求>'
```

常用操作见 [说明书](references/manual.md)，完整命令与参数以各脚本及子命令 `--help` 为准；创作工具字段见 [本地工具](references/local-tools.md)。

## 数据与隐私

- 偏好库与任务快照只写到 `--data-dir` 指定的目录，程序拒绝写入源码目录。
- 存档包含母版与你的成品原文，属于私人数据，不要随仓库提交（见 `.gitignore`）。
- 全部离线运行：不联网、不上传、不调用图像模型，只用 Python 标准库。

## 能力边界

不自动出图，不验证图像质量。语义复核来自宿主声明，程序只保证结构与哈希一致，不独立判断语义等义。本版不含数据导入导出、迁移包、API 路由与图像编辑。

知识内容、程序检查和加载成功都不证明真实图像质量。

## 本地发行校验

使用上文已设置的解释器与技能目录绝对路径：

```powershell
& $py -B -X utf8 "$skillDir\scripts\release.py" verify
& $py -B -X utf8 "$skillDir\scripts\release.py" build --output '<源码之外的新ZIP绝对路径>'
```

校验版本、逐文件哈希、组件范围及常见敏感数据；这不是完整安全审计或真实图像验收。目标ZIP存在时拒绝覆盖。不联网、不调用图像模型，也不上传GitHub。
