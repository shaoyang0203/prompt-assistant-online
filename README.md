# Prompt Assistant Online V1.4.0 Harness

围绕人物与环境关系进行视觉设计的文生图提示词助手。主要方向为电影氛围、幻想电影与诗性自然摄影：先确认目标模型和风格，讨论画面，再按六步形成视觉母版，最后由目标模型 Adapter 编译提示词。

本版从 V1.3.0-harness 独立复制更新，新增本地风格推荐与画幅决策，保留已有 Harness 数据安全修复。当前为本地发行交付，未自动发布 GitHub或替换已安装技能。

## 本版变化

- [本地风格推荐库](references/风格推荐库.md) 预写六个条目，包含推荐说明、适用题材和设计依据。首次风格未明确时选取相关条目询问；LLM 不需要重新总结自身擅长什么。
- 风格已明确或用户授权自选时继续设计；模型和风格都缺省时同一次简短询问补齐。通用交付不是风格，翻译、校对和保真格式迁移不增加风格问答。
- 已选风格从构思阶段参与画面瞬间、构图、光色、材质及人物与环境关系，不仅在成品中追加风格名称。
- Grok 当前网页端从 2:3、3:2、1:1、9:16、16:9 中推荐，块外给比例和一句具体构图理由，由界面选择。API 列表与网页菜单分开。
- 画幅根据动作、视线、尺度和空间展开决定；人物不固定竖幅，氛围与电影感不固定宽屏。
- 修改方案先复核连带关系：局部修改、主动同步修复，或涉及已定核心取舍时询问重设计范围。已明确授权重设计时直接执行。
- 摄影提示词明确一次正向媒介表达，例如 `Photorealistic photography.`；已有同义表达就沿用。其他媒介服从用户要求。

## 本地六个风格条目

| 条目 | 推荐侧重 |
| --- | --- |
| 克制电影摄影 | 人物位置、观看距离、局部光影和空间层次 |
| 霓虹都市电影摄影 | 城市灯色、反射与街道纵深 |
| 诗性自然摄影 | 自然光、风、细微动作和空间呼吸感 |
| 东方仪式电影摄影 | 建筑尺度、造型与光色秩序 |
| 暖金宫廷幻想摄影 | 暖金灯光、深暖空间及丝绸珠宝层次 |
| 极简史诗幻想摄影 | 人物与巨大空间的尺度差、几何大形和克制色彩 |

库内条目是推荐和设计资源，当前用户明确的风格、媒介和硬要求优先；前景、虚化、光线及环境交互按画面需要组织，不是每图必填。既有暖金与黑金造型知识继续保留在视觉设计系统中。

## 安装与使用

1. 解压完整安装包 `V1.4.0-harness.zip`。
2. 使用其中完整的 `prompt-assistant-online-v1-4-0-harness/` 目录，入口为 `SKILL.md`。按所用宿主的 Skill 安装方式切换，避免新旧同时自动调用。
3. 有文件读取能力即可使用核心创作知识；宿主能执行 Python 3.10+ 并访问独立持久目录时，才可使用 Harness 脚本持久化。
4. 继续使用原外部数据目录，或导入迁移包。不要用空模板覆盖个人偏好。

首次开场为“正在调用提示词助手 V1.4.0 Harness”，随后显示真实的 `[递归优化 --开]`、`[递归优化 --关]` 或 `[递归优化 --不可用]`。状态和首次说明在 Prompt 代码块外，后续不重复开场。

个人数据路径按 `--data-dir`、`PROMPT_HARNESS_DATA_DIR`、用户主目录 `.prompt-assistant/harness` 选择。新安装默认关闭递归优化，经验写入另需明确授权；无可靠持久化时继续设计并如实说明未保存。

## 数据与升级

数据格式仍为 1。明确兼容 1.2.0-harness、1.2.1-harness、1.22、1.3.0-harness、1.4.0-harness 各自匹配的技能身份。

保留 V1.3.0 的定向 forget、确认 clear、冲突与去重、独立健康状态、轻量审计、原子快照及导入边界。forget/clear 不自动清理历史 generation、审计文件和备份，不代表历史原文彻底擦除。纯偏好导入保留本地引擎、授权、会话和设置；harness/full 导入继续关闭引擎与授权并重置会话，三类导入先备份。

详细命令、字段与隐私边界见 [数据格式与迁移](harness/README.md) 和 [Harness 说明](references/harness-help.md)。根目录 [用户偏好模板](用户偏好.md) 是空白历史迁移模板，运行时不写入。

## 验证与限制

- 自动化：129 项原有回归 + 4 项新增包完整性和迁移回归，共 133 项。结果见 [原始测试报告](harness/test-results.json)。
- 行为验收：[设计案例](tests/design-cases.json) 共 28 项，其中新增 12 项覆盖本版交互和画幅等方向；它们是待执行的 Agent 行为任务，不计入 133 项自动化测试，不声称 Grok 已通过。
- 发行检查：结构、引用、VIP 基线、可重放文档修订、缓存与个人状态检查、ZIP CRC、逐文件 SHA256 和解包复测，见 [交付报告](交付报告.md)。

这些检查验证文件、迁移和存储逻辑，不能证明艺术质量提升。本版未做更新后的 Grok 实际出词/出图和跨平台实测；此前局部失败实验未被固化为全局风格禁令。`harness/design-review.json`、`pre-patch-test-results.json`、`patch-verification.json` 等是随原版保留的历史证据，应按其原版本理解。
